# src/assets/fonts/
Custom font files loaded via index.css @font-face or Google Fonts import.
VocaQuest uses:
- Inter (body/UI)      — fonts.google.com/specimen/Inter
- JetBrains Mono (XP)  — fonts.google.com/specimen/JetBrains+Mono
Both are loaded via Google Fonts CDN in index.html.
Place local .woff2 files here if self-hosting fonts.
